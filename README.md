タスク管理アプリ
概要

Flaskを用いて作成したタスク管理アプリです。
タスクの追加・編集・削除・一覧表示（CRUD機能）を実装しています。

使用技術
・Python
・Flask
・SQLite
・Bootstrap

機能
・タスク追加
・タスク一覧表示
・タスク編集
・タスク削除

工夫した点
・SQLiteを用いてデータの永続化を実現
・Bootstrapを使用してUIを改善し、操作性を向上

起動方法
pip install -r requirements.txt
python app.py
